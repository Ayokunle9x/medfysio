# Medfysio

A responsive healthcare landing page built with React and Vite. It introduces
Medfysio's health information, wellness resources, and care services.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite to view the site.

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server with hot reload. |
| `npm run build` | Create the production build in `dist/`. |
| `npm run preview` | Preview the production build locally. |
| `npm run lint` | Run ESLint across the project. |

## Features

- Responsive layout with mobile navigation.
- Search that jumps to a matching section on the page.
- Healthcare services, wellness articles, and expandable article details.
- Local SVG illustrations and photography assets.
- Newsletter signup form interface.

The newsletter form is currently a front-end demonstration. Connect a
newsletter provider or backend before collecting subscriptions.
